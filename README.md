# 🔮 Karmic Nodes & Astrocartography ✨

Welcome to the **Karmic Nodes & Astrocartography** app! 🌠 This super cute and powerful React + Vite application helps you explore real-time Lunar Node transits and Jim Lewis Global Planetary Angle Projections (Astrocartography). 🌍💫

## 🌟 Features
- 🗺️ **Astrocartography World Map**: Visualize celestial lines on Earth!
- 🎡 **Celestial Wheel & Shifts**: Track cosmic shifts in real-time.
- ⏳ **Nodal Return Cycles**: Discover milestones in your 18.6-year nodal cycles.
- 🌀 **Power Vortexes**: Explore famous global vortexes and their astrological resonance.
- 🔔 **Transit Alerts**: Get notified for exact aspects with a customizable orb threshold!

## 🚀 Getting Started

1. **Install dependencies**:
   `npm install`

2. **Start the development server**:
   `npm run dev`

3. **Build for production**:
   `npm run build`
