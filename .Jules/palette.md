## 2026-10-30 - Added ARIA labels to icon-only close buttons
**Learning:** Found a recurring pattern in modal components where close buttons (using only the `X` icon from lucide-react) were lacking accessible names (`aria-label`), making them difficult for screen readers to identify.
**Action:** Always verify that buttons containing only icons and no text have a descriptive `aria-label` added for proper accessibility.
## 2026-11-02 - Added ARIA labels and Focus Visibility to Control Buttons\n**Learning:** AstroMap and TransitTimeline had icon-only buttons for zoom, reset view and play/pause missing keyboard focus visibility and accessible names, which are essential for keyboard and screen reader users.\n**Action:** Add dynamic `aria-label` attributes to icon-only buttons corresponding to their state or function. Apply `focus-visible` tailwind classes (e.g. `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[color]`) to ensure clear visual focus indicators.
